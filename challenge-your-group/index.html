Reaction Test

Challenge your friends, family or class

Reaction and memory tests are made for friendly rivalry. Everyone thinks they are quick; everyone is surprised. With a few rules to keep things fair, the tests on this site make a good round at a family gathering, a week-long league in a WhatsApp group or a lively ten minutes in a classroom. Here are formats that work.

The golden rule: one device

Scores from different phones cannot be compared fairly, because each device adds its own delay; see why scores differ by device. For any contest in one room, pass a single phone or use one computer. For a contest between people in different places, compare improvement or rank within your own device, or use the memory tests, which do not depend on timing.

Format 1: the family pentathlon

Five tests, one device, everyone has one counted attempt at each after one practice go.

  1. Reaction time
  2. Aim
  3. Tap speed
  4. Sequence memory
  5. Number memory

Scoring: in each test, the best player gets as many points as there are players, the next one point fewer, and so on down to one. Add up the five events. This way no single talent wins everything; the quick-fingered teenager usually loses ground on number memory to a parent who chunks phone numbers every day.

Format 2: generations

Teams by generation: children, parents, grandparents. Each team's score in an event is its members' middle score. Give the younger and older teams an agreed head start if you like. The memory events often go to the elders, which is a pleasant surprise for everyone.

Format 3: a WhatsApp group league

  • Choose one test for the week. The memory tests are fairest across different phones.
  • Each member has until nine at night to play and send the result. The Share button after each test writes the message.
  • One attempt counts per day; honour system.
  • A volunteer keeps the table and posts it each night.
  • Change the test each week.

For timed tests in a spread-out group, score by improvement: each member's best of the week against their own first-day score.

Format 4: classroom

  • Projector version. Put the tile memory or number memory test on the screen. The whole class watches the flash; one pupil at the keyboard enters the answer the class agrees on by show of hands. It turns into a discussion of memory methods.
  • No-device version. The ruler drop test in pairs, with results gathered on the board and a class average worked out.
  • Experiment version. Half the class tests in silence and half while counting backwards; compare. See how to test fairly.

Format 5: office break

One laptop on a table, the reaction test, a sheet of paper for names and scores, a week's time and a small prize. Keep it opt-in and light, and publish the top five only.

Fair-play rules

  • One practice go, then the counted attempt. No "that one did not count".
  • Same hand position for all: finger hovering, or finger on the table, as you agree.
  • For tap speed, agree "one finger only" or "anything goes" beforehand.
  • No coaching during memory tests.
  • A spoilt attempt, such as a phone call arriving mid-test, may be replayed once.

Handicaps that keep it fun

  • Adults use the weaker hand.
  • Small children get the best of three.
  • Last week's winner goes first, without a practice go.

Kindness

These are games. Reaction time is slower in childhood and in later life, and everyone has slow days. Celebrate improvement and funny mistakes, and never use a score to tease someone or to judge what they can do. Nothing here measures intelligence, health or ability at anything except tapping a screen.

The tests

  • Reaction time
    Tap when it turns green
  • Sound reaction
    Tap when you hear the beep
  • Go / no-go
    Tap for green, not for orange
  • Aim
    Hit 20 targets
  • Tap speed
    Taps in 10 seconds
  • Sequence memory
    Repeat a growing pattern
  • Number memory
    Remember longer numbers
  • Tile memory
    Remember which tiles lit up
